# OpenWalkieTalkie @VERSION@ · Rev @REV@ 工厂 SPI NOR 烧录说明

**本包仅用于 Rev @REV@ 主板，只包含这一种硬件版本的固件。投产前请核对实物主板版本。**

本包用于通过离线烧录器直接烧写 SPI NOR 芯片。完整镜像已包含 Flash 分区表、
USB 恢复引导程序（协议 2）、正式应用和中文字库，无需另行烧写任何固件组件。

## 烧录参数

| 项目 | 设置 |
| --- | --- |
| 镜像文件 | `Rev-@REV@/OpenWalkieTalkie-@VERSION@-factory-@BOARD@.bin` |
| 适用主板 | **Rev @REV@** |
| 固件版本 | `@VERSION@-openwalkietalkie` |
| 文件大小 | **16,777,216 字节（16 MiB / 128 Mbit）** |
| 芯片内起始偏移 | **0x00000000** |
| 写入长度 | **0x01000000** |
| 写入范围（含起止） | **0x00000000–0x00FFFFFF** |
| 烧录器操作 | **整片擦除 → 空白检查 → 写入 → 全片读回校验** |

**这是整片镜像，会覆盖芯片中的配对、设置及板级数据。不得使用应用分区偏移，也不得填入 MCU 映射地址。**
不要只跳过镜像中的 `FF` 区域而保留芯片上的旧数据。

## 选择芯片型号

在烧录器中选择实际装配的 **3 V / 128 Mbit SPI NOR** 型号，按对应器件规格设置电压。
下列三种 U4 使用同一份本包镜像，无需按品牌更换固件：

| 料号 | 型号 | JEDEC ID（线上顺序） |
| --- | --- | --- |
| C97521 | Winbond W25Q128JVSIQ | EF 40 18 |
| C5354566 | Puya PY25Q128HA-SUH-IR | 85 20 18 |
| C2928891 | GigaDevice GD25Q128ESIGR | C8 40 18 |

读取芯片 ID，确认与所选型号一致；容量必须为 128 Mbit。

## 校验烧录包

解压后，在本目录运行以下命令，只检查文件，不访问设备：

```sh
python3 verify.py
```

Windows 安装 Python 3 后运行 `py -3 verify.py`。全部 4 个文件应显示 `OK`，并提示校验通过。
macOS 也可执行 `shasum -a 256 -c SHA256SUMS`；Linux 可执行 `sha256sum -c SHA256SUMS`。
`manifest.json` 记录镜像及各组件的 SHA-256、大小和芯片内偏移。

## 产线操作

1. 核对主板为 **Rev @REV@**，核对芯片型号、JEDEC ID 及容量。
2. 校验烧录包；加载上表中唯一的 `.bin` 文件，确认大小为 **16,777,216 字节**。
3. 将芯片起始偏移设为 **0x00000000**，写入长度设为 **0x01000000**。
4. 执行整片擦除及空白检查，确认整片为 `FF`。
5. 写入镜像，再执行覆盖整个 16 MiB 的读回比较。必须全部一致，才可判定烧录通过。
6. 完成装配后断电再上电，进行下方首件验收。

烧录或读回校验失败的芯片不得流入下一工序。检查接触、供电、型号及文件校验和后重新擦除烧录。
如有板级校准或个性化数据写入工序，应安排在整片烧录之后。

## 首件验收

本包已执行软件布局、组件一致性与校验和检查；尚未完成本版镜像的 SPI NOR 离线烧录及 Rev @REV@ 首件实测。
请对实际采用的主板及 Flash 组合完成首件确认，再批量生产：

1. 烧录器完整读回校验通过，记录镜像 SHA-256。
2. 装配后冷启动正常；屏幕方向、触摸、按键与旋钮正常。
3. 设置 → 关于显示 **`@VERSION@ · Rev @REV@`**。
4. 连接桌面 App，确认主板为 Rev @REV@，固件为 `@VERSION@-openwalkietalkie`，恢复协议为 `2`。
5. 检查扬声器和麦克风；验证蓝牙配对，重启后确认配对及设置可保存。
6. 抽检不同设备的 USB 序列号不同，并验证恢复模式与后续 USB 固件更新。

首件记录应包含主板版本、U4 料号、镜像 SHA-256、烧录器型号/软件版本和测试结果。

## 镜像布局（芯片内偏移）

| 起止偏移（含起止） | 内容 |
| --- | --- |
| 000000–007FFF | Flash 分区表（实际 11,280 字节，其余 FF） |
| 008000–00FFFF | 保留/板级配置区，初始 FF |
| 010000–01FFFF | 协议 2 恢复引导程序，剩余 FF |
| 020000–6FFFFF | 应用代码、常量及初始化数据 |
| 700000–70FFFF | 原生蓝牙数据库，初始 FF |
| 710000–71FFFF | 配对/设置日志，初始 FF |
| 720000–FFFFFF | 应用资源及中文字库，未用空间 FF |

镜像由发布组件和全新分区表合并生成，不来自某台设备的 Flash 拷贝，也不含已有配对密钥或用户设置。
USB 序列号及蓝牙地址在运行时由 MCU 的 UID 派生。本包不包含板级射频校准结果；
整片重烧会清除已写入外部 Flash 的校准或个性化数据，MCU 内部 eFuse 不属于本镜像。
