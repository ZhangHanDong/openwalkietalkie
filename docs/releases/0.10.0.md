OpenWalkieTalkie 0.10.0 adds a live view of your Mac's CPU, memory, GPU and storage on the deck. It also reduces Flappy Bird display transfers and gives all three Arcade games longer original music arrangements.

## Computer resources on the deck

The new **System** page shows four meters:

- **CPU:** total processor utilization, normalized across all cores.
- **Memory:** used and total memory, including app, wired and compressed memory.
- **GPU:** graphics utilization from the Mac's driver counters; the busiest accelerator is shown when there is more than one.
- **Storage:** free and total space on the writable startup volume. Its percentage means **free space**, so a low value is highlighted.

The Mac service samples every **two seconds**. Only meters whose displayed values change are repainted. Missing counters show **Not available**; readings older than ten seconds are marked **STALE**, and a lost host is marked **OFFLINE**. The first CPU percentage appears after two samples.

This page is **deck-only** and separate from subscription Usage. It follows Usage in a fresh default layout. Existing saved layouts are preserved: **double-tap Shift → + → System → Enter** to add the page. Update both the Mac app/service and the firmware; older services do not supply these readings, and the new service does not send System telemetry to unsupported firmware.

## Flappy Bird rendering

Flappy Bird now updates the bird, pipes and score regions instead of invalidating the entire screen for every simulation step. The firmware packs partial rectangles to match the display controller's transfer layout, handles the rotated Rev A/B panels, and schedules the next simulation step around time already spent rendering. A failed display transfer forces a complete repair on the next frame.

The shared-renderer regression traversal transfers **51.5% fewer pixels on average** across 360 frames with multiple and recycled pipes. This measures transfer area, not hardware frame rate. Tests compare partial updates with full redraws, including score changes, pause, game over and rotated panels. Display TE synchronization remains disabled; no tear-free or fixed-FPS claim is made.

## Longer Arcade music

Each game now has a **48-bar** synthesized arrangement with an intro, theme, answering melodies, quieter middle, build and return:

| Game | Full loop |
| --- | ---: |
| Flappy Bird | 96 seconds |
| Snake | 115.2 seconds |
| Raiden | 76.8 seconds |

Bass patterns, percussion and pulse timbres vary through the arrangement. Pausing or retrying the same game preserves the music position; selecting a different game starts its own theme. **Arcade → Sound → Enter** still cycles Off, SFX only and Music + SFX.

## Update

Install the signed, notarized macOS app for Apple Silicon or Intel, or choose **Check for Updates**. macOS 13 or later is required. Connect the deck over USB-C and choose **Service → Updates → Check firmware**. The app, deckd and firmware all report **0.10.0**. If an older service is still running, use **Service → Restart**.

Normal application updates preserve settings and Bluetooth pairing. Recovery protocol 2 and the flash layout are unchanged; older bootloaders use the existing guided migration. Board-specific factory ZIPs remain available for manufacturing and overwrite settings and pairing; use the app updater for an existing device.

## Validation

The 0.10.0 firmware was flashed, verified and rebooted successfully over USB on Rev A, and the Mac sampler returned all four resource metrics. Automated checks cover System message validation, compatibility gating, coalescing and freshness, rendering, partial-frame correctness, simulation timing, and music continuity across pauses and loop boundaries. Rev B hardware and physical power-loss recovery were not re-tested for this feature.
