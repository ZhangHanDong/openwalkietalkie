# OpenWalkieTalkie 0.10.0 升级说明

0.10.0 在 deck 上新增电脑资源页面 **System**，显示 Mac 的 CPU、内存、GPU 和磁盘剩余空间。同时改善 Flappy Bird 的局部刷新，并延长三款游戏的合成背景音乐。

## 电脑资源页面

- **CPU**：所有核心合计后的归一化使用率，范围 0–100%。
- **Memory**：已用／总内存，包括应用、不可换出（wired）和压缩内存。
- **GPU**：读取显卡驱动提供的利用率；多 GPU 时显示最忙的一颗。
- **Storage**：启动磁盘可写数据卷的可用／总空间。百分比表示**剩余空间**，空间较少时会改变提示颜色。

Mac 服务每 **2 秒**采样，只重绘显示值发生变化的表条。不可用的指标显示 **Not available**；超过 10 秒没有新数据时显示 **STALE**，主机断开后显示 **OFFLINE**。CPU 百分比需要两次采样后才会出现。

该页面仅在 **deck** 上提供，与订阅额度的 Usage 页面分开。新默认布局中，System 位于 Usage 后方。已有布局保持原样，请在 deck 上**双击 Shift → + → System → Enter** 添加。

需要同时更新 Mac 应用／deckd 服务和设备固件。旧服务不会发送电脑资源数据，新服务也不会向不支持此功能的旧固件发送这些消息。

## Flappy Bird 刷新

游戏按小鸟、管道和分数所在区域进行局部刷新，减少每个仿真步的整屏传输。固件按显示控制器要求打包局部像素，处理 Rev A／Rev B 的旋转屏幕，并在安排下一帧时扣除已经用于渲染的时间。传输失败后，下一帧会完整修复画面。

共享渲染器的 360 帧回归场景中，平均传输像素减少 **51.5%**。这是传输面积测量，**不是实机帧率**。测试覆盖管道循环、分数变化、暂停、结束和旋转屏幕；TE 同步仍未启用，不宣称固定帧率或完全无撕裂。

## 更长的 8-bit 背景音乐

三首音乐均改为 **48 小节**编曲，包含前奏、主题、回应旋律、安静段落、渐进与回归，低音、打击乐和脉冲音色会随段落变化。

| 游戏 | 完整循环长度 |
| --- | ---: |
| Flappy Bird | 96 秒 |
| Snake | 115.2 秒 |
| Raiden／雷电 | 76.8 秒 |

暂停或重试同一游戏会保留音乐进度，切换游戏才从新主题开始。通过 **Arcade → Sound → Enter** 切换关闭、仅音效或音乐＋音效。

## 安装

安装适用于 Apple Silicon 或 Intel 的签名、公证版 Mac 应用，或选择 **Check for Updates**。要求 macOS 13 或更新版本。通过 USB-C 连接 deck，打开 **Service → Updates → Check firmware** 更新设备。

Mac 应用、deckd 和固件版本均为 **0.10.0**。若旧服务仍在运行，请使用 **Service → Restart**。普通应用固件升级保留设置和蓝牙配对；Recovery 协议 2 和 Flash 分区保持不变，旧引导程序使用现有的引导式迁移流程。

工厂完整镜像继续分别提供 Rev A／Rev B ZIP，写入会覆盖设置和配对；已有设备请使用应用中的固件更新功能。

0.10.0 固件已在 Rev A 上通过 USB 烧录、校验并成功重启，Mac 采样器成功返回四项资源数据。自动化检查覆盖协议校验、兼容性限制、刷新与过期状态、局部渲染、仿真计时和音乐连续性。本次功能未重新进行 Rev B 实机或物理断电恢复测试。
