# OpenWalkieTalkie 0.4.0 内部升级测试

本测试包用于验证已出货设备从 **0.3.0 升级到 0.4.0** 的完整流程，包括临时升级程序、Bootloader 和正式固件。支持 Rev A、Rev B；桌面安装包仅支持 **Apple Silicon Mac，macOS 13 或更新版本**。

**Rev B 真机升级尚待团队验证。本包供内部测试，请勿作为正式版本向客户发布。** 不需要先发布到 GitHub：应用内已包含两种硬件版本的固件及校验清单，断网也可以完成升级。点击检查时可能先等待最多约 10 秒的在线检查。

## Mac 首次打开提示

本包使用 Developer ID 签名，但**尚未经过 Apple 公证**，因为打包电脑没有可用的公证凭据。它仅供团队内部测试；在另一台 Mac 上首次打开时，系统可能提示 Apple 无法检查应用。

请先核对测试包来源和 SHA-256。若只是未公证提示，可由测试人员在尝试打开后进入“系统设置 → 隐私与安全性”，找到本应用的“仍要打开”，再确认“打开”。无需关闭系统整体安全检查。如果提示应用损坏或包含恶意软件，请停止并反馈，不要强行运行。具体界面参见 [Apple 官方说明](https://support.apple.com/zh-cn/102445)。

## 文件说明

- `OpenWalkieTalkie-0.4.0-macos-aarch64.dmg`：Mac 应用安装包。
- `firmware/`：Rev A、Rev B 的正式固件、临时升级程序、恢复 Bootloader 和 `firmware-manifest.json`。
- `SHA256SUMS`：测试包文件的 SHA-256 校验值。
- `VALIDATION.txt`：本地构建、软件检查及真机测试记录。
- `package-manifest-aarch64.json`：DMG 的签名、公证及校验信息。

`hw-a` 对应 Rev A，`hw-b` 对应 Rev B。正常升级请只操作 GUI，**不要把 `bootstrap` 或 `recovery` 文件当作正式应用固件手动烧录，也不要混用不同版本的文件**。这里不包含整片工厂烧录镜像，也不需要手动重写分区表。

## 安装与升级

1. 保留一台仍运行 0.3.0 的 Rev B，记录 PCB 版本和设备序列号，确认使用的是数据线而非仅充电线。
2. 退出旧版 OpenWalkieTalkie，打开 DMG，把 `OpenWalkieTalkie.app` 拖入“应用程序”，替换旧版本，再从“应用程序”打开。确认应用版本为 **0.4.0**。若服务仍显示旧版，在 `Service` 页面点击 `Restart`，等到服务版本也为 **0.4.0**。
3. 用 USB-C 将设备直接连接到 Mac。升级时保持 USB-C 连接、设备供电及电脑唤醒，避免通过不稳定的扩展坞连接。
4. 打开 `Service → Updates`，点击 `Check firmware`。应显示正确的 Rev B、USB 序列号、已安装 0.3.0、可用 0.4.0。若设备已经处于恢复模式且无法自动报告硬件版本，请依据 PCB 标识选择 **Rev B**。
5. 点击 `Update firmware…`，确认出现 **“Bootloader update — power must stay connected”** 警告。先点击 `Cancel`，确认升级没有开始，再重新打开确认界面。
6. 阅读警告后点击 `I understand — update device`。此后无需手动操作：应用会安装临时升级程序、备份并替换 Bootloader、完整读回校验，再安装正式固件。
7. 等到 GUI 显示 **“Firmware updated. Your deck is ready.”**。确认已安装版本为 **0.4.0-openwalkietalkie**；设备的 About 页面应显示 **0.4.0 · Rev B**。Rev A 对应显示 **0.4.0 · Rev A**。

旧 Bootloader 只能使用旧 HID 传输方式，因此第一次安装临时升级程序仍需要数分钟。新 Bootloader 的后续阶段可使用 USB bulk；写入变化扇区还需额外的 Flash 擦写时间。不要把第一阶段较慢误判为卡死。

## Bootloader 更新注意事项

Bootloader 是设备上电后首先运行的软件。在替换它的短暂窗口内断电，可能导致设备既无法启动，也不能通过 USB 恢复，需要硬件恢复。**不要在该阶段拔线、关机或进行断电测试。** GUI 会显示相应的警告和更新阶段。

升级程序会保留蓝牙配对及偏好设置存储区，并在重启前校验 Bootloader。若出现错误，请保存完整错误信息并保持供电；尤其是提示不要重启时，切勿自行断电。只有 GUI 明确提示可重试时才重试，不要尝试刷写其他硬件版本的镜像。

如升级失败，请提供：PCB 版本、USB 序列号、升级前后版本、Mac 型号及系统版本、出现错误的阶段、GUI 完整错误截图和服务日志。日志入口为 `Service → Open log`。

Bootloader 备份保存在：

```text
~/Library/Caches/OpenWalkieTalkie/firmware/bootloader-backups/
```

请保留原始测试包、校验文件和日志。无需上传蓝牙配对数据。

在解压后的测试包目录执行以下命令，可核对文件完整性：

```sh
shasum -a 256 -c SHA256SUMS
```
