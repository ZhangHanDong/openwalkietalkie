# OpenWalkieTalkie 0.5.0 升级说明

本版本修复 Codex Desktop 连接和短任务回复遗漏，增加两种替代 Flash 的固件支持，并提供工厂合并镜像。应用、deckd 和正式固件版本均为 0.5.0。

## 安装 Mac 应用

要求 macOS 13 或更新版本。请从本项目 v0.5.0 Release 下载适合 Apple Silicon 或 Intel 的正式 DMG，核对 SHA256SUMS。正式包使用 Developer ID 签名并经过 Apple 公证；也可在应用内使用 **Check for Updates**。

安装后确认应用和 Service 页中的 deckd 均为 0.5.0。

## 启用或修复 Codex Desktop

1. 在 OpenWalkieTalkie 的 **Integrations → Codex Desktop** 中安装或修复集成。
2. 等待 Desktop 中的任务空闲，再退出 Codex Desktop / ChatGPT。
3. 打开 `~/Applications/Codex with OpenWalkieTalkie.app`。这是启动器，会打开已安装的 Desktop，并连接到 OpenWalkieTalkie 使用的同一个本地 Codex 服务。以后也请用它启动。
4. 新建本地任务，例如发送 `Reply exactly DESKTOP-LINK-OK. Do not use tools.`，然后在 OpenWalkieTalkie 和设备上选择对应任务，查看回复。

直接打开原始 Desktop 应用不会启用这条共享连接。启动器兼容符合要求的 ChatGPT.app 和 Codex.app，不会自动终止正在运行的任务；如果 Desktop 版本不支持所需连接方式，会明确提示错误。0.5.0 还会补取订阅之前就已完成的短任务回复。

## 更新设备固件

1. 用 USB-C 数据线连接一台设备，保持 Mac 唤醒和设备供电。
2. 打开 **Service → Updates → Check firmware**，核对板型、USB 序列号和目标版本 0.5.0。
3. 点击 **Update firmware…** 并按提示操作。已使用 recovery protocol 2 的设备只更新应用固件，分区表与 0.4.0 相同。
4. 等待成功提示，确认固件为 **0.5.0-openwalkietalkie**，设备 About 为 **0.5.0 · Rev A** 或 **0.5.0 · Rev B**。

**旧 Bootloader 设备需要迁移。写入 Bootloader 时断电可能使设备无法启动，也无法通过 USB 恢复，需要硬件维修。整个升级期间请勿拔线、关机或让电脑休眠。** 应用会显示警告并要求确认，然后自动安装临时升级程序、备份和替换 Bootloader、完整读回校验，再安装正式固件。第一次通过旧 Bootloader 的 HID 传输仍需数分钟。

不要手动把 bootstrap 或 recovery 文件作为应用烧录，不要混用 Rev A / Rev B 镜像。正常 GUI 升级保留蓝牙存储区，不重写分区表。

## Flash 选型与工厂镜像

支持的 U4 器件为 Winbond W25Q128JVSIQ（C97521）、Puya PY25Q128HA-SUH-IR（C5354566）和 GigaDevice GD25Q128ESIGR（C2928891）。固件在写入前校验稳定的 JEDEC ID，拒绝未知器件。替代器件仍需实板验证后才能批准量产替换。

`OpenWalkieTalkie-0.5.0-factory.zip` 包含 Rev A、Rev B 各自的 16 MiB 合并镜像、中文 README、组件清单、SHA256SUMS 和 verify.py。镜像由本次正式应用/恢复程序和全新分区表生成，设备存储区为空。

**工厂镜像仅用于空白板初始化，会覆盖全部 Flash，包括设置、配对和设备数据。已出货设备请使用 GUI 升级。** MCU UART 下载地址为 `0x12000000`，独立 SPI 编程器偏移为 `0`。烧录前阅读 ZIP 内 README、核对板型并运行 `python3 verify.py`；量产前完成首件烧录、冷启动和功能检查。

## 验证范围

Desktop 启动器和传输回归测试通过。本机实测 Desktop 已连接共享服务，OpenWalkieTalkie GUI 显示 `DESKTOP-LINK-OK`，连接的 Rev A USB 投递正常；未记录最后一次物理屏幕目视确认。

两个板型均通过软件检查。此前包含相同 Flash 支持的 0.4.1 开发固件在现有 Rev A 上完成了旧 Bootloader 迁移；该测试不等于本次 CI 重新构建的 0.5.0 文件已经过硬件验证。已出货 Rev B、装配替代 Flash 的板子及空白板工厂烧录仍待团队实测。本轮未测试设备音频。
