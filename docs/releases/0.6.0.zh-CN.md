# OpenWalkieTalkie 0.6.0 升级说明

0.6.0 为设备新增 Arcade 游戏页：Flappy Bird、贪吃蛇和雷电。三个游戏使用完整的 480×480 屏幕，支持可关闭的原创 8-bit 背景音乐和音效。Mac 应用、deckd 服务和设备固件版本均为 0.6.0。

## 安装与升级

1. 从 v0.6.0 Release 下载适合 Apple Silicon 或 Intel Mac 的 DMG，核对 SHA256SUMS。正式包使用 Developer ID 签名并经过 Apple 公证，要求 macOS 13 或更新版本；也可在应用中使用 **Check for Updates**。
2. 安装后确认应用及 Service 页面中的 deckd 均为 0.6.0。
3. 用 USB-C 数据线连接一台设备，保持设备供电和 Mac 唤醒，打开 **Service → Updates → Check firmware**，安装 0.6.0 固件。
4. 已有面板布局不会被覆盖。若看不到 Arcade，**双击 Shift → + → Arcade → Enter** 添加，再双击 Shift 退出管理器。新设备默认布局已包含 Arcade。

使用 0.4.0/0.5.0 分区布局及 recovery protocol 2 的设备只需更新应用固件，无需重新迁移 Bootloader。

**仍使用旧 Bootloader 的设备需走 GUI 引导迁移，并先确认风险提示。迁移期间不可断电、拔线或让 Mac 睡眠；写入 Bootloader 时断电可能导致设备无法启动和 USB 恢复，需要硬件维修。不要把 bootstrap 或 recovery 文件当作普通应用固件手动烧录。**

## 三个游戏

| 游戏 | 操作 |
|---|---|
| Flappy Bird | 按 PTT 拍翅膀；Arcade 中的 PTT 只控制游戏，不开启麦克风、不发送给 AI agent。 |
| 贪吃蛇 | 顺时针转轮向右转，逆时针向左转；Left / Right 键也可转向。屏幕圆角处有墙，食物始终位于可见区域。 |
| 雷电（Raiden） | Left / Right 移动，飞机自动开火；敌机机头朝下，有三条命。 |

Enter 用于开始、暂停、继续或重试；Cancel 返回游戏列表。切换到其他页面会暂停游戏。游戏过程中只叠加分数，操作说明在准备和暂停界面显示。最高分保留到设备重启。

## 音乐与音效

在 **Arcade → Sound → Enter** 循环选择 **Off → SFX only → Music + SFX**，也支持触屏操作。默认 Off，音量跟随 Speaker 设置。三个原创背景乐循环和七种音效由设备本地合成，无需下载音频文件。游戏声音会让位于主机语音播放和录音。

连接匹配版本的 Mac 服务时，服务保存并恢复音效选项；离线设置只在当前开机期间有效，下次启动默认关闭。

## 团队验证建议

- 更新后确认设备 About 页面为 0.6.0，Arcade 可以加入已有布局。
- 分别检查三个游戏的全屏显示、按键/转轮、暂停/继续、重试和返回。
- 检查 Flappy Bird 的 PTT 不触发录音，贪吃蛇食物不会生成在不可见圆角中，雷电敌机朝向正确。
- 在适合播放声音的环境中，检查三档音效设置、Speaker 音量、语音打断和静音恢复；此轮开发未进行设备音频播放测试。
- 检查 Mac 服务连接时的音效偏好恢复，以及设备重启后最高分清零。

游戏逻辑、声音合成、协议、设置保存和局部刷新有软件测试。开发期间已在 Rev A 烧录和试用游戏，包括全屏显示和敌机朝向修正；Rev B 游戏功能及音乐/音效听感仍需实板验证。

## 工厂文件

`OpenWalkieTalkie-0.6.0-factory.zip` 包含 Rev A、Rev B 各自的 16 MiB 合并镜像、中文烧录说明、组件清单、SHA256SUMS 和 verify.py。

**工厂镜像用于空白板初始化，会覆盖全部 Flash，包括设置和蓝牙配对数据。已出货设备应使用 GUI 升级。** MCU UART 下载地址为 `0x12000000`，独立 SPI 编程器偏移为 `0`；烧录前核对板型并运行 `python3 verify.py`。
