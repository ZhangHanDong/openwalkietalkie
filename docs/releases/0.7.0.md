OpenWalkieTalkie 0.7.0 improves device speaker playback with host-side EQ and restores RAM execution on Rev A to reduce flash-coupled hiss.

## What changed

- Apply speaker EQ in **deckd** before sending mixed speech and chimes over USB or Bluetooth LE. The fixed preset uses a 250 Hz high-pass filter, a −5 dB cut at 1.1 kHz, and a −6 dB cut at 6.3 kHz, with 3 dB of headroom and a −1 dBFS sample ceiling.
- Preserve filter state across audio blocks and silence, and reset it when the output reopens. Invalid samples cannot poison subsequent audio.
- Restore **Rev A code, constants, and font assets in PSRAM**, with interrupt vectors in SRAM. Startup verifies the copies and returns to USB recovery after three failed attempts. Rev B and LilyGo retain execution from NOR.
- Preserve the existing flash partitions and both Bluetooth stores. Rev A's upper-bank font load image is copied to RAM at startup; the final MiB of PSRAM remains reserved for diagnostics.
- Add checks for board-specific execution layout, startup copy boundaries, vector placement, protected flash storage, and the EQ that reaches the encoded device stream.

The preset is enabled automatically on the custom 16 kHz device audio output. It does not boost the speaker's deep-bass roll-off or narrow response dips, and bass-heavy material can sound quieter. It does not process locally generated Arcade audio, legacy CoreAudio output, or raw measurement tones. This release does not add an EQ toggle.

## Install

Install the signed, notarized macOS app for Apple Silicon or Intel, or use **Check for Updates**. macOS 13 or later is required. Confirm the app and service both report **0.7.0**, connect one deck over USB-C, then use **Service → Updates → Check firmware**.

Devices already using recovery protocol 2 receive a normal application update. Devices with the old bootloader need the existing guided migration: follow the app's power and USB instructions and accept its warning before proceeding. Use the GUI updater for an existing device; full-chip factory images overwrite settings and pairing data.

## Validation

The EQ and RAM-execution changes were exercised on a Rev A board over USB. Speech playback completed without dropped host audio frames, the operator reported substantially reduced hiss, and a labeled bass comparison using the same EQ implementation was preferred with EQ enabled. These are listening results, not a new calibrated acoustic measurement. Rev B hardware and Bluetooth-only listening were not tested in this session.

The release pipeline checks the host tests and lint, shared firmware and renderer tests, all board builds, normal and migration image layouts, firmware packaging, and checksums before publishing.

The release includes both Mac packages, signed update feeds, Rev A/B application and migration images, ELFs, factory images, updater manifests, SHA-256 checksums, build attestations, and the Chinese upgrade guide (`README.zh-CN.md`, also inside the DMGs). Factory ZIPs are separate for each hardware revision (`factory-hw-a.zip` and `factory-hw-b.zip`); each contains only that board's 16 MiB image and Chinese instructions for direct SPI NOR programming at chip offset zero.
