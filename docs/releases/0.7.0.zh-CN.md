# OpenWalkieTalkie 0.7.0 升级说明

0.7.0 在 Mac 端 deckd 中加入扬声器 EQ，并恢复 Rev A 从 RAM 运行，以减少外部 Flash 读取耦合到扬声器的嘶声。Mac 应用、deckd 服务和设备固件版本均为 0.7.0。

## 安装与升级

1. 从 v0.7.0 Release 下载适合 Apple Silicon 或 Intel Mac 的 DMG，核对 SHA256SUMS。正式包使用 Developer ID 签名并经过 Apple 公证，要求 macOS 13 或更新版本；也可在应用中使用 **Check for Updates**。
2. 安装后确认应用及 Service 页面中的 deckd 均为 0.7.0。
3. 用 USB-C 数据线连接一台设备，保持设备供电和 Mac 唤醒，打开 **Service → Updates → Check firmware**，安装 0.7.0 固件。

已使用 recovery protocol 2 的设备只需更新应用固件，无需重新迁移 Bootloader。已有 Flash 分区及两个蓝牙存储区保持原址。

仍使用旧 Bootloader 的设备需走 GUI 引导迁移，并确认应用中的风险提示。迁移期间保持供电和 USB 连接；写入 Bootloader 时断电可能导致设备无法启动和 USB 恢复。不要把 bootstrap 或 recovery 文件当作普通应用固件手动烧录。

## 扬声器 EQ

deckd 在混音、重采样之后，PCM 量化和 ADPCM 编码之前处理输出，通过 USB 或 Bluetooth LE 发送到设备。固定预设自动启用：

| 滤波器 | 频率 | 增益 |
|---|---|---|
| 高通，12 dB/octave | 250 Hz | — |
| 峰值均衡 | 1.1 kHz | −5 dB |
| 峰值均衡 | 6.3 kHz | −6 dB |

预留 3 dB 余量，采样峰值限制在 −1 dBFS。滤波状态跨音频块及静音连续保留，重新打开输出时复位。异常采样不会污染后续音频。

该预设根据扬声器频响图作保守调整，不补偿深低频衰减或窄陷波；低音较多的内容可能更轻、更小声。本版本没有 EQ 开关。设备本地产生的 Arcade 声音、旧 CoreAudio 路径及原始测量音不经过此 EQ。

## Rev A 降噪

Rev A 启动时把代码、常量和字体复制到片内封装的 PSRAM，并把中断向量表移到 SRAM，避免正常播放期间频繁读取 PCB 上的外部 NOR Flash。每段复制都会校验，连续三次失败后返回 USB 恢复模式。

字体在 Flash 中仍位于上半区；代码、常量、字体副本及运行缓冲区须放入 PSRAM 前 7 MiB，最后 1 MiB 继续保留给诊断。Rev B 和 LilyGo 继续直接从 NOR 运行。

## 验证情况

开发期间在 Rev A 实板通过 USB 验证了语音和低音独奏对比。语音播放没有主机音频丢帧，试听反馈为嘶声明显改善，并偏好启用 EQ 的效果。这是试听结果，不是新一轮校准声学测量；本轮未进行 Rev B 实板或纯蓝牙连接的试听。

发布流程会检查主机测试与 lint、共享固件和渲染测试、各板型构建、普通及迁移镜像的内存布局、固件打包与校验和。

## 工厂文件

工厂包按主板版本分别发布，每个 ZIP 只含一种硬件的 16 MiB 合并镜像、中文 SPI NOR 离线烧录说明、组件清单、SHA256SUMS 和 verify.py：

- Rev B：`OpenWalkieTalkie-0.7.0-factory-hw-b.zip`
- Rev A：`OpenWalkieTalkie-0.7.0-factory-hw-a.zip`

工厂镜像用于空白板初始化，会覆盖全部 Flash，包括设置和蓝牙配对数据。已出货设备应使用 GUI 升级。SPI NOR 烧录器起始偏移为 `0x00000000`，写入长度为 `0x01000000`；烧录前核对板型并运行 `python3 verify.py`，执行整片擦除及完整读回校验。
