OpenWalkieTalkie 0.8.0 adds an automatic screen lock to prevent accidental PTT presses in a bag and makes page and item selection follow the same wheel direction.

## Screen lock

- After two minutes without local input, the display sleeps and all local controls lock, including PTT.
- A button, touch, or wheel turn lights the lock screen without activating the underlying control. Turn the wheel **counterclockwise four consecutive ticks** to unlock; the waking tick counts. Clockwise rotation or another sleep resets progress.
- The unlocking tick is consumed. A button held while locked must be released and pressed again before it can act, so a trapped PTT cannot start transmitting when the wheel unlocks the device.
- Notifications can light the display but cannot unlock it. A held button cannot keep the locked display awake indefinitely.

## Wheel navigation

The physical encoder direction is corrected. **CCW selects next/down; CW selects previous/up**, both for SHIFT + wheel page selection and for menu items, agent/session lists, card choices, and list scrolling. The tutorial follows the same page direction.

Numeric settings, including volume, still increase clockwise. Assigned Macropad bindings and in-game turns retain their physical direction. Unlocking remains four CCW ticks.

## Install and factory packages

Install the signed, notarized macOS app for Apple Silicon or Intel, or use **Check for Updates**. Then connect the deck over USB-C and use **Service → Updates → Check firmware** to install 0.8.0. The app, deckd, and device firmware all report 0.8.0. Devices already using recovery protocol 2 receive a normal application update that preserves settings and Bluetooth pairing. Older recovery versions use the app's existing guided migration.

Rev A retains RAM execution and the host speaker EQ introduced in 0.7.0. Rev B retains NOR execution. Flash partitions and recovery protocol are unchanged.

Factory ZIPs remain separate for each board: `OpenWalkieTalkie-0.8.0-factory-hw-a.zip` and `OpenWalkieTalkie-0.8.0-factory-hw-b.zip`. Each contains only that board's 16 MiB full-chip image and Chinese instructions for direct SPI NOR programming at chip offset zero. Factory images overwrite settings and pairing; use the app updater for existing devices.

## Validation

Development firmware was flashed and verified on a Rev A deck over USB; the operator confirmed the physical wheel-direction correction. Automated checks cover lock/unlock timing, held and queued inputs, PTT suppression, wheel selection and boundaries, rendering, and board-specific execution layouts. Rev B hardware was not field-tested in this session.

The release pipeline checks all board builds, shared firmware and renderer tests, host tests and lint, application and migration packages, and checksums before publishing. Assets include the two Mac packages, update feeds, board-specific firmware and factory images, manifests, checksums, build attestations, and the Chinese guide (`README.zh-CN.md`).
