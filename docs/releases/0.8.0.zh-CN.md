# OpenWalkieTalkie 0.8.0 升级说明

0.8.0 新增自动锁屏，防止设备放在包内时误触 PTT；同时统一页面切换和列表选择的滚轮方向。Mac 应用、deckd 服务和设备固件版本均为 0.8.0。

## 自动锁屏

1. 连续两分钟没有本地操作后，屏幕熄灭，按键、触摸和滚轮进入锁定状态，PTT 也不会触发录音或发送。
2. 任意操作会点亮锁屏界面，但不会执行该操作。
3. **连续逆时针转动滚轮四格即可解锁**。用于唤醒的第一格计入进度；顺时针转动或再次休眠会清零进度。
4. 解锁的第四格不会继续移动页面或选中项。锁定期间按住的按键必须先松开、再重新按下才能生效；因此，即使解锁时 PTT 仍被包内物品压住，也不会自动开始发送。

通知可以点亮屏幕，但不能解锁。持续按住按键也不会使锁屏一直亮着。

## 滚轮方向

| 操作 | 逆时针 | 顺时针 |
|---|---|---|
| SHIFT + 滚轮 | 下一页 | 上一页 |
| 列表和菜单选择 | 下一项／向下 | 上一项／向上 |
| 锁屏 | 连续四格解锁 | 清零解锁进度 |

会话列表、卡片选项、设置行和菜单使用相同的选择方向。新手引导中的页面切换也保持一致。音量等数值设置仍为顺时针增加；已分配的 Macropad 滚轮快捷键和游戏中的转向按实际物理方向工作。

## 安装与升级

1. 下载适合 Apple Silicon 或 Intel Mac 的 0.8.0 DMG，并核对 SHA256SUMS；也可在应用中使用 **Check for Updates**。正式包经过 Developer ID 签名及 Apple 公证，要求 macOS 13 或更新版本。
2. 安装后确认应用和 Service 页面中的 deckd 均为 0.8.0。
3. 用 USB-C 数据线连接设备，保持供电，在 **Service → Updates → Check firmware** 中安装 0.8.0 固件。

已使用 recovery protocol 2 的设备只更新应用固件，保留设置和蓝牙配对。旧版恢复程序的设备按应用内既有引导迁移；不要把 bootstrap 或 recovery 文件作为普通应用固件使用。

本版本继续保留 0.7.0 的 deckd 扬声器 EQ 和 Rev A 的 RAM 运行方式。Rev B 继续从 NOR 运行，Flash 分区和恢复协议不变。

## 工厂 SPI NOR 烧录

工厂包按主板版本分别发布，**每个 ZIP 只包含一种硬件版本的镜像**：

- Rev B：`OpenWalkieTalkie-0.8.0-factory-hw-b.zip`
- Rev A：`OpenWalkieTalkie-0.8.0-factory-hw-a.zip`

每包包含 16 MiB 合并镜像、中文烧录说明、组件清单、SHA256SUMS 和 verify.py。工厂通过 SPI NOR 烧录器直接写入芯片：起始偏移 `0x00000000`，写入长度 `0x01000000`。烧录前核对板型并运行 `python3 verify.py`，执行整片擦除及完整读回校验。工厂镜像会覆盖设置和蓝牙配对，已出货设备请使用应用内升级。

## 验证情况

开发固件已在 Rev A 实板通过 USB 烧录并校验，操作人员确认了物理滚轮方向修正。自动化测试覆盖锁屏和解锁、长按与排队输入、PTT 拦截、列表方向及边界、画面渲染和各板型内存布局；本轮未做 Rev B 实板测试。

发布流程会在公开版本前检查全部板型构建、固件与渲染测试、主机测试和 lint、普通及迁移镜像、软件包和校验和。
