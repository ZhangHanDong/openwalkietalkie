# OpenWalkieTalkie 0.9.0 升级说明

0.9.0 新增 48 kHz USB 扬声器播放，改善 16 kHz 音频的编码与重建质量，并在 Mac 和设备的 Usage 页面提醒即将到期的手动重置额度。Mac 应用、deckd 服务和设备固件版本均为 0.9.0。

## USB 语音播放

- Mac 服务在设备固件声明支持时，自动以 **48 kHz** 通过 USB 发送扬声器音频；旧固件自动回退至 16 kHz。
- 两种采样率均保留扬声器 EQ。USB／BLE 切换及松开 PTT 后，播放会按协商后的采样率重新打开。
- 固件只接受由 USB 明确启动的 48 kHz 音频，并增加缓冲以覆盖功放启动时间。**BLE 扬声器和麦克风采集仍为 16 kHz**。
- 16 kHz 主机编码器搜索多个 ADPCM 预测路径以减少量化误差；若原算法误差更低，则保留原结果。固件使用带限 FIR 插值，将 16 kHz 音频重建为 DAC 使用的 48 kHz。

在 Rev A 的英语 TTS 对比中，两段均开启 EQ，音量接近；试听者认为 48 kHz 的词语更清晰、噪声更少。两种采样率均未出现音频缺口、欠载、队列丢包或序号错误。改进后的 16 kHz 编码器在同一语段上的平方编码误差降低约 30%，但尚未通过试听确认新版 16 kHz 路径完全消除了嘶声。BLE 48 kHz 尚未启用，也未完成持续传输验证。

## 手动重置额度到期提醒

当服务商返回的未使用手动重置额度将在 **72 小时内**到期时，Mac Usage 页面和设备 Usage 页面会在每周用量条下方显示琥珀色提示，例如“2 resets expire in 1d 6h”。

该提示与每周额度自动恢复倒计时不同。它只统计最早到期时间相同的额度；额度用完、过期或账户切换后会清除相应提示，断开连接时隐藏。没有可用服务商数据时不显示提示，也不会自动兑换重置额度。

## 安装与升级

1. 下载适合 Apple Silicon 或 Intel Mac 的 0.9.0 DMG，并核对 SHA256SUMS；也可使用 **Check for Updates**。正式包经过 Developer ID 签名及 Apple 公证，要求 macOS 13 或更新版本。
2. 安装后确认应用和 Service 页面中的 deckd 均为 0.9.0。
3. 用 USB-C 数据线连接设备，保持供电，在 **Service → Updates → Check firmware** 中安装 0.9.0 固件。

48 kHz USB 播放及完整的 16 kHz 改善需要同时更新服务和固件。已使用 recovery protocol 2 的设备只更新应用固件，保留设置和蓝牙配对；旧恢复程序按应用内既有引导迁移。Flash 分区和恢复协议不变，Rev A 保持 RAM 运行，Rev B 保持 NOR 运行。

## 工厂 SPI NOR 烧录

- Rev A：`OpenWalkieTalkie-0.9.0-factory-hw-a.zip`
- Rev B：`OpenWalkieTalkie-0.9.0-factory-hw-b.zip`

每个 ZIP 只包含对应板型的 16 MiB 合并镜像、中文说明、组件清单、SHA256SUMS 和 verify.py。SPI NOR 烧录起始偏移为 `0x00000000`，写入长度为 `0x01000000`。烧录前核对板型并运行 `python3 verify.py`，执行整片擦除及完整读回校验。工厂镜像会覆盖设置和蓝牙配对，已有设备应使用应用内升级。
