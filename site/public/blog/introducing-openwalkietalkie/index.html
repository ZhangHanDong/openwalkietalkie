OpenWalkieTalkie v0.1.0: a handheld for your agents

October 13, 2026First official release

OpenWalkieTalkie puts your coding agents on a small handheld screen. See which session needs you, hold push-to-talk to reply, and answer a question with the wheel and buttons.

A conversation you can carry

The 480 × 480 touch screen shows agent sessions and their conversations. Messages use the available screen space, tool activity stays compact until you expand it, and code has syntax highlighting. The view follows new messages while you are at the end.

Release push-to-talk and the transcript stays on screen while speech recognition finishes. The completed transcript is sent to the selected agent. Usage shows the active Claude or Codex account alongside its limits.

Mac app and device updates

Version 0.1.0 includes a signed and notarized Mac app for Apple Silicon and Intel, on macOS 13 or later. The app includes automatic app updates and USB firmware updates that check the connected board before flashing.

Rev A and Rev B firmware, checksums, and build attestations are available with the release. A first flash still requires a compatible bootloader; subsequent updates can run through the app.

Download the Mac app or read the full release notes and firmware instructions.

Open from the board up

The repository includes firmware, the Mac app and host service, editable CoHDL schematics, KiCad board layouts, and enclosure CAD. Software is MIT licensed; the hardware designs use CERN-OHL-P 2.0. Third-party components keep their own licenses.
