OpenWalkieTalkie v0.2.0: workflows at a glance

October 13, 2026App and firmware update

OpenWalkieTalkie v0.2.0 makes it easier to follow work that keeps running in the background. The Mac app and handheld now show live workflow progress alongside your agent conversations.

Follow the work

Open a session and switch to Workflow to see its plan and compact tool activity. Claude Dynamic Workflows also show each run’s name, progress bar, completed and started worker counts, elapsed time, and token count. Background runs keep updating while the parent conversation is quiet.

The device keeps the current workflow page visible until the replacement arrives, fixing the blink during periodic refreshes. Scroll position stays in place, and tool details remain expandable.

Usage for the account you are using

The Mac app has a dedicated Usage page, and both app and device include Claude Fable’s weekly usage limit when the account provides it. Each meter shows the active account, usage percentage, and reset time. Claude and Codex limits stay visible together.

Get v0.2.0

Use Check for Updates in the Mac app or download the signed and notarized package for Apple Silicon or Intel. macOS 13 or later is required.

For the device, connect by USB and open Service → Updates in the app. Check for firmware, review the selected board, and install v0.2.0. Rev A and Rev B images are included; a first flash still requires the compatible bootloader.
